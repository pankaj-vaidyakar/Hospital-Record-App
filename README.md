# 🏥 Hospital – Doctor Records App

A simple web application to manage hospital doctor records. This project allows users to add, view, and delete doctor details using a clean and user-friendly interface.

---

## 📌 Features

- Add doctor details using a form  
- Display doctor records dynamically in a table  
- Assign doctor role automatically based on experience  
- Delete doctor records easily  
- Beginner-friendly and easy to understand logic  

---

## 🧑‍⚕️ Doctor Role Logic

- **Senior Doctor** → Experience > 5 years  
- **Junior Doctor** → Experience between 2 to 5 years  
- **Trainee** → Experience ≤ 1 year  

---

## 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript (DOM Manipulation & Event Handling)
